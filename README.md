# Food Guide India (FGI)

Modern Next.js rebuild of the legacy Food Guide India concept — regional Indian recipes, ingredient search, filters, and chef profiles.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the next available port if 3000 is in use).

## Build

```bash
npm run build
npm start
```

## Features

- **Enter Your Kitchen** — search recipes by ingredients you have
- **Recipe filters** — state, religion, cuisine, cooking time, method, serves, veg/non-veg
- **Recipe detail pages** — steps, ingredients, ratings, share
- **Ingredients encyclopedia** — history, regional names, nutrition
- **Master Chefs** — verified chef profiles
- **Add Recipe** — community submission form (UI ready)

Legacy HTML wireframes are preserved in `/legacy`.
